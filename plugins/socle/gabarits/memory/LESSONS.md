# LESSONS

Quelle erreur ne pas refaire : un bloc `L-NNN` après CHAQUE correction humaine. Le numéro se prend en relisant ce fichier au moment d'écrire.

Format :

```
## L-001 · titre court · AAAA-MM-JJ
- Symptôme : ce qui a été vu
- Cause : pourquoi c'est arrivé
- Règle : ce qui empêche la récidive
```

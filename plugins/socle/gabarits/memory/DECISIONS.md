# DECISIONS

Pourquoi c'est comme ça : un arbitrage non évident par bloc `D-NNN`. Le numéro se prend en relisant ce fichier au moment d'écrire.

Format :

```
## D-001 · titre court · AAAA-MM-JJ
- Contexte : ce qui forçait à trancher
- Décision : ce qui est retenu
- Alternatives écartées : et pourquoi
```
